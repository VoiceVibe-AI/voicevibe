# Security

Thank you for helping keep VoiceVibe and its users safe.

## Reporting a vulnerability

**Please do not report security issues in public GitHub issues.**

Report them privately through GitHub:
[Report a vulnerability](https://github.com/VoiceVibe-AI/voicevibe/security/advisories/new)
(the **Security** tab of this repository, then **Report a vulnerability**).
Only you and the VoiceVibe team can see the report.

Please include:

- the VoiceVibe version and your operating system;
- what the issue is and what an attacker could do with it;
- steps to reproduce, or a proof of concept;
- any logs or screenshots, with personal information removed.

Please give us reasonable time to investigate and fix the issue before
you disclose it publicly, and do not access other people's accounts or
data while testing.

## Supported versions

Security fixes go into the latest release on
[voicevibe.ai/download](https://voicevibe.ai/download?utm_source=github&utm_medium=security).
Please update to it before reporting.

## Data handling

How VoiceVibe handles your data is described in the
[privacy policy](https://voicevibe.ai/privacy). In short, Free Voice
Typing runs entirely on your device, and Pro modes send the audio and
context you include to the cloud for processing, encrypted in transit.
